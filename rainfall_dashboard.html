Analysis and Visualization of Historical Rainfall Patterns in India

A Python project using Pandas, NumPy, Matplotlib, Seaborn and BeautifulSoup to explore 115 years of rainfall across 36 meteorological subdivisions.

PythonNumPyPandasMatplotlibSeabornRequestsBeautifulSoup

Overview

Rainfall shapes agriculture, water resources and the environment. This project cleans, analyses and visualises historical records to reveal patterns across months, years and regions.

Objectives

  1. Analyse historical rainfall data in India.
  2. Clean and process data with Pandas.
  3. Numerical calculations with NumPy.
  4. Compare months, years and subdivisions.
  5. Represent patterns with charts.
  6. Retrieve rainfall info via web scraping.

Dataset

Rainfall in India (1901–2015)
Kaggle · by rajanand

Monthly, annual and seasonal rainfall (Jan–Feb, Mar–May, Jun–Sep, Oct–Dec) for each subdivision and year.
